# Lab Experiment 2: File Integrity Verification Using SHA-256

## Aim

To understand the concept of cryptographic hashing and verify file integrity using the SHA-256 hashing algorithm in Python.

## Objective

- Create a text file and write data into it.
- Generate a SHA-256 hash of the original file.
- Modify the content of the file.
- Generate a new SHA-256 hash.
- Compare both hashes to detect whether the file has been modified.

## Requirements

- Python 3.x
- hashlib module

## Algorithm Used

SHA-256 (Secure Hash Algorithm 256-bit)

SHA-256 is a cryptographic hash function that converts input data into a fixed-length 256-bit hash value.
